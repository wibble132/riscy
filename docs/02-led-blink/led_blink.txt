But the rp2350 does have timer peripherals (12.8)

TIMER0: 0x400b0000
1. read timer timelr(+x0c), then timerhr(+x08), to get 64bit current time
2. add 1million (1mill us -> 1s) = 0xF4240 --> LIMIT
3. in a loop:
3.1.   read time again
3.2    break if > LIMIT

This is still a busy spin loop, but it will be based on us instead of estimating from clock ticks
