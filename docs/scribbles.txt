UF2 Format Details

All data destined for device is in UF2 blocks with:
- familyID (see 5.5.3)
- payload_size of 256

Must be for within the range 0x1000_0000-0x1200_0000, with 256-byte alignment. Writes beyond end of *physical* flash with wrap to beginning of flash!

- numBLocks must specify total size of binary that fits in the region
- change in numBlocks will cause discard
- change in familyID will discard
- must be in blocks without UF2_FLAG_NOT_MAIN_FLASH marking


UF2 Format:

series of 512-byte blocks. each block is:
 - 0x0A324655
 - 0x9E5D5157
 - Flags (can be zero)
 - target address
 - bytes of data (256)
 - block number (starts 0, increments)
 - total block count in file
 - file size or (board family ID if flag set) or zero
 - (many) data
 - 0x0AB16F30

See minimal.uf2 for this simplest uf2 file, that contains the Minimum viable image metadata (5.9.5.)

In the blink example:

put: write to SIO GPIO_OUT_SET/GPIO_OUT_CLR
set_dir: out - write to SIO GPIO_OE_SET, in - write to SIO GPIO_OE_CLR
set_function - as above, write to BANK0 GPIO to set IE, unset OE. Then set GPIO_CTRL to SIO


so
- set_dir(IN):
  - SIO(0xd0000000) GPIO_OE_CLR(+0x040), write (1 << 25)
- put(0):
  - SIO(0xd0000000) GPIO_OUT_CLR(+0x020), write (1 << 25)
- set_function(SIO)
  - BANK0(0x40038000) GPIO25(+0x68)
    - read
    - & ~(1 << 7)
    - | (1 << 6)
    - write
  - IO Userbank(0x40028000) GPIO25_CTRL(+0x0cc), write 0x05
- set_dir(OUT)
  - SIO(0xd0000000) GPIO_OE_SET(+0x038), write (1 << 25)
- put(0):
  - SIO(0xd0000000) GPIO_OUT_SET(0x018), write (1 << 25)

x10: 0xd0000000 (10 = 0x01010) (SIO BASE)

x12: 0x40028000 (12 = 0x01100) (IO Userbank base)
x13: 0x40038000 (12 = 0x01101) (BANK0 base)
x14: temp var   (13 = 0x01110)
